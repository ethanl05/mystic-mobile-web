## 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 技术栈 | Next.js + TypeScript + Tailwind CSS | 方案文档指定，适合移动端 Web App 快速迭代 |
| 测试框架 | Vitest（或 Jest） | 与 TypeScript + Next.js 配合好，速度快 |
| Phase 1 真太阳时 | 不实现 | 降低复杂度，Phase 2 再做 |
| Phase 1 支付 | 不实现 | 方案明确"不接支付，用测试账号模拟权益" |
| Phase 1 登录 | 不实现 | 用内置测试账号模拟 |
| 引擎策略 | 测试先行 | 方案强调"排盘和起卦一旦错，后面的 AI 解读再漂亮也没有意义" |
